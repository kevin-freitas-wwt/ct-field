00 · The field

The mark is
a field.

Nothing on this page is an image. Every character is resolved from a luminance field by the same five-stage script that makes every CT render, and the field is alive. Move through it. Each section falls into one region of it.

01 · The pipeline

How a render is made.

One script, five stages. The same neutral solid is carried through every stage so the effect of each step is visible in isolation.

01 Sourceluminance, no processing
02 Rastersupersampled 10× per cell
03 Fieldblurred · 0.75 × cell
04 Contoursharpened · 0.34 / 0.36
05 Resolvetwo layers · dormant blue, lit orange
02 · Interpolation

Fields, not pixels.

Two fields are mixed and a single contour is re-resolved, so the solid deforms. A crossfade would show both shapes at once. At t = 0.50 there is exactly one form on screen and it belongs to neither end.

t = 0.50deformed · one contour, no ghost

03 · Constants

The constant is an asset.

Each value holds everything else fixed. Too little blur and the contour is jagged with no gradient to morph; too much and strokes fuse. The shipped setting is a published style, not a number someone remembers.

blur 0.750.0 none · 0.75 · 1.15 welded
threshold 0.340.18 fat · 0.34 · 0.52 skeletal
cell 0.62leading ÷ size · at 1.00 glyphs shear 1.67×
04 · Two-tone

The field is never one colour.

A resolved render is split into two layers over the same grid. Cells inside the attention region go to the lit layer; everything else stays dormant. Two layers, not per-character colouring, so there can only ever be one lit region. The rule is enforced by structure, not discipline.

field/dormantrecedes · blue-400 light, blue-100 dark
field/litadvances · signal-400 in both modes
05 · The type family

The alphabet is the same transformation as the mark.

Archivo Bold through the same five stages as any other source, one glyph at a time, against one baseline. Cap height is the size axis: inside a field the font size never changes, so density carries the value. A title face and a mark. Never a reading face.

06 · Tokens

Roles. Aliased, never raw.

Twenty-nine primitives, sixteen semantic roles. Designers apply only the roles. Each role points at a primitive per mode, so Dark is a mode switch rather than a second library. Toggle it in the corner: the whole page restyles.
